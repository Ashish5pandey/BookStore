# Book Management System - Frontend

## Overview
This is a frontend application for a Book Management System built using React.js. It allows users to view a list of books fetched from a backend service and displays them in a styled table format.

## Technologies Used:
- **React.js**: For building the user interface with reusable components.
- **Axios**: For making HTTP requests to fetch data from the backend API.
- **Bootstrap**: For responsive styling and layout of the application.
- **JavaScript (ES6)**: For managing component state and rendering logic using modern JavaScript features.

## Features
- Displays a list of books with ID, name, and price.
- Fetches book data from a backend service using Axios.
- Responsive design for better user experience.
